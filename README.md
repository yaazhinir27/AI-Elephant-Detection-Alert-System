# AI-Driven Elephant Detection & Real-Time Alert System

## Project Description

An AI-driven real-time elephant detection and alert system developed
using Python, YOLO, Machine Learning, and Computer Vision for wildlife
monitoring and elephant intrusion detection.

## Technologies Used

- Python
- YOLO
- Machine Learning
- Computer Vision
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Key Features

- Real-time elephant detection
- Automated alerts
- Sound-repellent control
- Weather-based monitoring
- Detection history
- Real-time monitoring dashboard

## My Contribution

## Outcome

The system provides an AI-based approach for monitoring elephant
intrusions and supporting timely response.
